Запусти діагностику:

`sh "${CLAUDE_PLUGIN_ROOT}/hooks/run.sh" -m keel doctor`

Код виходу 1 при статусі `fail` це результат, а не збій команди. Якщо запуск не вдався (наприклад, немає Python 3.11+ або `sh`), покажи помилку й поясни, що встановити.

Покажи загальний статус і версію. Далі для кожного пункту зі статусом `fail` або `warn`: що означає простими словами, чому це важливо і яка конкретна дія (поле `fix`, команда). Спершу `fail`. Пункти `ok` згадай лише кількістю.

`warn` «планувальник вимкнено» це свідомий стан, якщо людина його обрала: Radar тоді працює вручну.

Сам нічого не лагодь, запропонуй дію.

Наприкінці дай звіт блоком, придатним для пересилання: JSON із виводу як є. Він не містить коду й секретів, але містить шляхи до тек і назву системи: попередь про це, щоб людина могла їх прибрати.
