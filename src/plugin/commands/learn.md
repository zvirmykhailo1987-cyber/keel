description: "Один наступний крок розвитку й повторення карток"
argument-hint: "[--review <id> --quality 0..5]"
allowed-tools: Bash(sh *run.sh* -m keel learn)
---

Аргументи: `$ARGUMENTS`.

Без аргументів отримай один наступний крок:
`sh "${CLAUDE_PLUGIN_ROOT}/hooks/run.sh" -m keel learn`

Покажи рівно один крок за полем `type`:

- `review`: картка на повторення. Покажи лише `front` і попроси відповісти. Після відповіді покажи `back`. Оцінку якості 0..5 дає людина: 0 зовсім не згадав, 3 згадав із зусиллям, 5 легко. Нижче 3 картка починається спочатку. Потім:
  `sh "${CLAUDE_PLUGIN_ROOT}/hooks/run.sh" -m keel learn --review <id> --quality <0..5>`
- `practice`: найслабша навичка й рівень. Запропонуй одну конкретну вправу в поточному коді, якщо він є.
- `empty`: карта порожня. Вона наповниться після першого `/keel:retro`.

Рівень навички підвищує лише доказ: коміт, ревʼю, ретро. Самооцінка без доказу не приймається. Його записує `/keel:retro`.

Нову картку додавай, якщо людина попросила:
`sh "${CLAUDE_PLUGIN_ROOT}/hooks/run.sh" -m keel learn --card <id> --front "<питання>" --back "<відповідь>"`
