---
description: "Ретро сесії: що пішло не так, корінь, правило; запис уроку й доказу рівня"
argument-hint: "[тема]"
---

Проведи ретро цієї сесії. Тема: `$ARGUMENTS`, а якщо порожньо, то вся сесія. Опирайся на те, що реально сталося: вивід команд, правки, відкати. Якщо опертись нема на що, чесно скажи, що уроку немає.

1. **Що пішло не так.** Перелік фактів: де витрачено зайвий час, що довелось переробляти, що виявилось хибним.
2. **Корінь.** Для кожного пункту: чому це сталося по суті, а не «забув» чи «неуважно». Якщо пояснення не передбачає наступного разу, копай далі.
3. **Правило.** Конкретна перевірка, яка б це зловила. Формулюй так, щоб її можна було виконати, а не «бути уважнішим».

Покажи людині чернетку й спитай, чи записувати. Далі:

**Урок** подай через рушій. Текст іде у vault, відкочується через `undo`:
```sh
sh "${CLAUDE_PLUGIN_ROOT}/hooks/run.sh" -m keel propose <<'JSON'
{"action":"add_lesson","params":{"title":"...","body":"Що сталося. Корінь. Правило.","evidence":"коміт, команда або файл"},"why":"...","source":"ретро сесії","confidence":0.9}
JSON
```
Якщо оболонка не підтримує heredoc, запиши JSON у тимчасовий файл і передай `propose --file <шлях>`. Без реального доказу в `evidence` урок не подавай. Секретів і чужих персональних даних у тексті бути не може.

**Рівень навички**, якщо робота це доводить:
`sh "${CLAUDE_PLUGIN_ROOT}/hooks/run.sh" -m keel learn --skill <назва> --evidence "<коміт, ревʼю чи ретро>" --level <N>`
Рівні: 0 новачок, 1 практик, 2 впевнений, 3 експерт. `--level` став лише тоді, коли доказ справді показує новий рівень. Самооцінка не є доказом.

**Граблі проєкту.** Якщо урок стосується цього репозиторію, запропонуй запис у `.keel/pitfalls.md`: що сталося, корінь, правило.

**Загальний для навички урок.** Якщо правило має діяти завжди в навичці Keel, а не лише тут, запропонуй покращити її методом `keel:self-improve`: уточнення записується в overlay у vault, проходить перевірки й 14 днів випробування, файли плагіна не міняються. Виконуй лише після згоди людини.

Покажи підсумок: що записано, шлях, `event` для відкату.
