---
id: G24
module: core
title: Вимога без інструменту
---
**Симптом:** стандарт каже «роби якісно», а готового матеріалу немає. Кожна генерація винаходить своє: emoji замість іконок, div-смужки замість графіків, різні обробники помилок.
**Корінь:** якість це не інструкція, а наявний склад готових деталей плюс перевірка їх ужитку. Інструкція без складу дає карго-культ, склад без перевірки стає мертвим вантажем. Вимога без інструмента або валить усе (G21), або її вимикають.
**Правило:** нову вимогу якості вводити парою: бібліотека плюс перевірка, в один крок. Добрий компонент із конкретної фічі переносити в спільну бібліотеку одразу. Періодично звіряти розрив «що є у фічах і що доступно спільно».
**Перевірка:** на кожне правило в CLAUDE.md чи гайді вказати, чим воно забезпечене й чим міряється; правило без цього позначити як недоставлене. `git grep` компонентів поза спільною текою.
**Приклад:** правило «помилки API обробляти однаково» плюс нічого більше дає пʼять різних обробників. Пара: спільна `apiFetch()` і лінт-правило, що забороняє прямий `fetch` у компонентах.
