---
id: G15
module: core
title: «Невідомо» кодується як «нуль»
---
**Симптом:** після дотику до фільтра-порогу половина записів зникає, і це виглядає як «таких об'єктів просто немає».
**Корінь:** `value or 0` стирає різницю між «не поміряно» і «поміряно й мало». Записи без значення падають у найменший клас або відсікаються порогом.
**Правило:** `null` і `0` це різні стани і в моделі, і у фільтрі. Для кожного порогу свідомо вирішити долю записів без значення й дати їх окремим перемикачем із лічильником. Окремий клас «невідомо» замість найменшого. В UI оцінене візуально відрізняти від неоціненого. Розбіжність джерел виносити у видиму колонку «перевірити», а не перезаписувати мовчки.
**Перевірка:** тест: запис із `None` не зникає мовчки після застосування фільтра; у звіті рядок «без значення: N» присутній; `git grep -nE "\|\| 0|or 0\b"` по числових полях.
**Приклад:**
```js
const size = num(r.size) || 0;              // погано: невідоме стає нулем
if (size < minSize) return false;           // і мовчки зникає
if (r.size == null) return showUnknown;   // добре: окрема, видима доля
```
