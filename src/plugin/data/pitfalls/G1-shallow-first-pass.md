title: Перший прохід без глибини
---
**Симптом:** після першої версії доводиться писати «перероби глибше». Код формально виконує запит, але пропускає аудиторію, крайові випадки й половину очікуваного складу.
**Корінь:** задачу починають без явного «для кого, навіщо й що входить у готове». Швидка чернетка «потім переробимо» коштує двох проходів замість одного.
**Правило:** перед кодом записати аудиторію, призначення й чекліст результату; звітувати N із N пунктів. Для нетривіальної задачі першим кроком зібрати вимоги (план-режим, уточнювальні питання). Перший прохід одразу повний за складом; обмежений обсяг узгоджувати явно, а не тихо урізати.
**Перевірка:** перед «готово» пройти чекліст по кожному пункту; вимога без тесту, файла чи демонстрації не закрита.
**Приклад:** запит «додай експорт звіту». Поверхнево: кнопка й CSV на щасливому шляху. Глибоко: хто читає, формат і кодування для Excel, порожній звіт, великий обсяг, права доступу, тест на кожне.
