title: Перевикористаний PID, мертвий процес «живий»
---
**Симптом:** після перезавантаження фоновий виконавець мертвий, але статус «живий», і кнопка старту каже «вже працює». Стоп за тим самим номером убив би чужий процес.
**Корінь:** PID це не ідентичність, а номер, який ОС перевикористовує. Збережений номер переживає процес (перезавантаження, сон, краш).
**Правило:** живий означає номер плюс імʼя образу з очікуваного переліку плюс час створення процесу не пізніше записаного старту (із невеликим допуском). Убивати лише після такої перевірки. Панель показує «режим увімкнено, виконавця немає» як помилку, а не очікування.
**Перевірка:** тести: власний процес із чужим переліком образів не живий; власний процес із записаним стартом у минулому не живий.
**Приклад:**
```python
def alive(pid, started_at):
    try:
        p = psutil.Process(pid)
    except psutil.NoSuchProcess:
        return False
    return p.name() in EXPECTED and p.create_time() <= started_at + 120
```
