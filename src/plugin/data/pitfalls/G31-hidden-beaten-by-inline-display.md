title: Атрибут hidden не ховає
---
**Симптом:** видно два взаємовиключні стани: банер «немає даних» світиться над заповненою таблицею. Логіка й розмітка правильні, гейти мовчать.
**Корінь:** інлайновий `display` перебиває правило браузера для `[hidden]`. Покладання на стиль за замовчуванням там, де інлайнові стилі звичні.
**Правило:** у базовий CSS додати `[hidden]{display:none !important}`: це семантика «цього немає», а не оформлення, тому `!important` доречний.
**Перевірка:** у консолі кожного екрана: `[...document.querySelectorAll('[hidden]')].filter(e => e.offsetParent !== null).length` дає 0 (для `position:fixed` перевірити окремо).
**Приклад:**
```html
<div hidden style="display:flex">Записів ще немає</div> <!-- видно -->
```
