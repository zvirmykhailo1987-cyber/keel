---
id: G14
module: core
title: «Неможливо» до вичерпного пошуку
---
**Симптом:** після 1–2 очевидних спроб звучить «цього API немає», «бібліотека не вміє», «дані лише платно». Наступне запитання людини показує, що рішення лежало поруч.
**Корінь:** перевірили профільне місце, а дані чи можливість зʼявляються й побічно. Висновок робили за прикладами, а не за специфікацією.
**Правило:** не заявляти «неможливо»; заявляти «перевірено X, Y, Z, там немає; лишились неперевірені A, B». Перебрати місця, де потрібне може бути побічно: схема, changelog, код бібліотеки, суміжні endpoint-и, експорт. Твердження про відсутність поля звіряти з офіційною схемою. Платний сервіс часто переупаковує відкрите джерело: шукати першоджерело. Метрику рахувати на релевантному знаменнику.
**Перевірка:** у висновку є перелік перевіреного; для твердження про API є посилання на схему чи OpenAPI і конкретний запит із відповіддю.
**Приклад:** «SDK не дає поля `updated_at`» сказано за трьома прикладами відповіді. У схемі воно є, а приходить лише з параметром `expand`.
