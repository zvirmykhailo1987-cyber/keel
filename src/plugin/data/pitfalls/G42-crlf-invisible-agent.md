---
id: G42
module: core
title: CRLF робить агента невидимим
---
**Симптом:** агента немає в списку сесії (`Agent type not found`), хоча файл є в `~/.claude/agents/`, а текстова перевірка каже «все гаразд». Голосної помилки немає.
**Корінь:** у виміряному випадку Claude Code не завантажував файли агентів із CRLF, а перевірка читала текст із нормалізованими закінченнями і міряла зміст, а не завантажуваність. Windows-інструменти й Python `open(p, "w")` без `newline` пишуть CRLF мовчки.
**Правило:** файли `agents/*.md` лише LF: правити інструментом Edit або Python із `newline="\n"`; `.gitattributes` із `eol=lf` для цієї теки. Агент зник: спершу порахувати CR, потім усе інше. Межа: у тому самому вимірі `SKILL.md` з CRLF завантажувались нормально, тому масова конвертація навичок не фікс. Поведінка залежить від версії, тож звір на своїй.
**Перевірка:** `python -c "import sys;print(open(sys.argv[1],'rb').read().count(b'\r'))" agent.md` дає 0. Гейт читає байти, а його selftest має фікстуру CRLF-агента.
**Приклад:** скрипт додає рядок в агента через `open(p, "w").write(text)` на Windows: весь файл стає CRLF, і агент зникає після наступного старту. Фікс: `open(p, "w", newline="\n", encoding="utf-8")`.
