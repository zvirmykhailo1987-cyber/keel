title: Перед «непридатне для машини»
---
**Симптом:** джерело відкидають за виглядом у браузері: SPA, порожній HTML, 403. Потім виявляється, що воно мало документований машинний канал.
**Корінь:** «сторінка не читається» приймають за «даних немає». Дивляться на HTML і не шукають API.
**Правило:** перед таким вердиктом обійти всі двері: публічний API (`/api`, `/data-api`), CSV чи JSON-експорт, raw-файл у репозиторії, `llms.txt`, друкована чи текстова версія URL. Вердикт «недоступне» отримує часову позначку, бо мерехтливий хост не означає закритих дверей. Лише коли всі двері закриті, чесний вердикт «не перевірено», а не «без змін».
**Перевірка:** у висновку перелік спробуваних дверей із кодом відповіді; вкладка Network браузера показує, звідки SPA бере дані.
**Приклад:** рейтинг рендериться через JS, і WebFetch бачить порожню сторінку. У репозиторії сайту лежить `data/leaderboard.json`, а на домені є `/print`-версія без JS.
