---
id: G38
module: core
title: Скрипт пише в згенерований файл
---
**Симптом:** скрипт відпрацював без помилки, артефакт є, а внесеної секції на сторінці немає. Помічають випадково, бо зникає вона на наступній збірці.
**Корінь:** у ланцюзі «шаблон, генератор, артефакт» місце для правок одне: шаблон. Запис в артефакт не падає голосно, він просто не переживає збірку.
**Правило:** ціль скрипта-вставника це шаблон чи джерело, ніколи `output/`. Якщо запис у генерований файл неминучий, генератор має про нього знати через плейсхолдер. Те саме для ручних правок: правити генератор, а не результат.
**Перевірка:** два прогони генератора поспіль, потім `grep -c "<маркер вставки>" output/page.html` дає очікуване число.
**Приклад:** `inject_charts.py` дописує блок в `output/page.html`, а `build.py` щоразу перезаписує цей файл із `templates/page.html`. Фікс: вставляти плейсхолдер у шаблон і заповнювати в `build.py`.
