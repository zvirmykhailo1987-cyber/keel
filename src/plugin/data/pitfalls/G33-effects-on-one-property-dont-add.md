---
id: G33
module: frontend
title: Два ефекти на одну властивість не додаються
---
**Симптом:** підйом і нахил окремо працюють, а разом лишається один, без жодної помилки. На скриншоті різницю не видно, ловить лише вимір матриці.
**Корінь:** `transform`, `filter`, `box-shadow` це одна властивість. Каскад не вміє композиції, він лише обирає переможця за специфічністю.
**Правило:** кожен ефект пише власний токен-доданок, а властивість збирається одним правилом зі сталим порядком. Порожній фолбек означає «доданка немає». Для `transform` можна також рознести ефекти на окремі `translate`, `rotate`, `scale`. Щойно ефектів на властивість двоє, вводиться складання.
**Перевірка:** увімкнути обидва стани й прочитати `getComputedStyle(el).transform`: значення має містити обидва внески.
**Приклад:**
```css
.card       { transform: var(--t-lift,) var(--t-tilt,) var(--t-drag,); }
.lift:hover { --t-lift: translateY(-4px); }
.tilt       { --t-tilt: rotateX(4deg); }
```
