title: Кирилиця, кодування й cmd.exe на Windows
---
**Симптом:** скрипт падає з `UnicodeEncodeError` на друці, файл читається кракозябрами, `.bat` ламається на дужках, посилання всередині ZIP биті.
**Корінь:** на Windows дефолтне кодування консолі й `open()` залежить від локалі (часто cp1251), а cmd.exe має власні правила розбору.
**Правило:** `.bat` лише ASCII+CRLF. `PYTHONUTF8=1` і явний `encoding="utf-8"`. Шляхи в лапках. Без `&&` після `start` і без дужок в `echo` всередині `if`. Імена файлів для передачі й логіни латиницею, бо кирилиця плюс ZIP дає биті посилання. Браузер відкривати лише після health-check сервера. Консольний друк має витримувати cp1251 або писати у файл.
**Перевірка:** `PYTHONIOENCODING=cp1251 python script.py` не падає; збірку розпакувати на чистій машині й пройти посилання.
**Приклад:**
```bat
@echo off
set PYTHONUTF8=1
start "" python "%~dp0serve.py"
python "%~dp0wait_health.py" || exit /b 1
start "" "http://localhost:8000"
```
