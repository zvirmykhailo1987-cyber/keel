---
id: G28
module: frontend
title: Неіснуючий CSS-токен працює на фолбеку
---
**Симптом:** сторінка виглядає правильно, помилок немає, але вимикач руху чи теми в цьому місці не діє. Користувач із вимкненим рухом усе одно бачить анімацію.
**Корінь:** `var(--x, 120ms)` перетворює друкарську помилку на робочу поведінку, а невизначена змінна в CSS не є помилкою. Один осиротілий `var()` мовчки вимикає гарантію системи токенів.
**Правило:** кожен токен визначений у ядрі або темі. Фолбек це запасний варіант, а не заміна визначення. Особлива увага до токенів, привʼязаних до вимикачів (рух, щільність, тема): там сирота означає відмову слухатись людину.
**Перевірка:**
```bash
comm -23 <(grep -rhoE "var\(--[a-zA-Z0-9-]+" src | sed 's/var(//' | sort -u) \
         <(grep -rhoE "^\s*--[a-zA-Z0-9-]+:" src | sed -E 's/^\s*//; s/://' | sort -u)
```
**Приклад:** `transition: opacity var(--motion-fast, 120ms)`, а `--motion-fast` ніде не визначено. Зашиті 120 мс не множаться на `--motion-scale`, тож `prefers-reduced-motion` їх не глушить.
