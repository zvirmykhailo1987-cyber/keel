---
id: G34
module: frontend
title: Спільний код знає словник лише однієї шкіри
---
**Симптом:** після зміни типової теми чи шкіри падають тести, перемикачі перестають підсвічуватись, а гейт міряє одну шкіру двічі. «Зламалось» те, чого не чіпали.
**Корінь:** перевіряють і обслуговують словник класів, а не намір. Поки шкіра одна, різниці немає. Інструмент також покладається на чужий дефолт.
**Правило:** тест перевіряє контракт: «помилка видима й оголошена» означає `aria-invalid` плюс банер із `role="alert"`, а не конкретний клас. Синоніми в одній константі зверху файла. JS спирається на `data-`-атрибути або перелічує словники обох шкір. Гейт завжди явно каже серверу, що міряє.
**Перевірка:** запустити весь набір тестів для кожної шкіри параметром; у звіті гейта друкувати фактично виміряну шкіру.
**Приклад:**
```js
// тендітно: expect(page.locator('.err')).toBeVisible()
await expect(page.getByRole('alert')).toBeVisible();
const group = el.closest('[data-toggle-group]');
```
