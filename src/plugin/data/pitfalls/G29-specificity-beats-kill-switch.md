---
id: G29
module: frontend
title: Специфічність перебиває вимикач
---
**Симптом:** анімація входу вимкнулась, тож на око все правильно, а нахил і підйом при наведенні далі рухаються в людини з вимкненим рухом.
**Корінь:** «вимкнено» реалізовано як ще одне значення з легшим селектором. Вимикач, який мусить бити все, слабший за те, що вимикає.
**Правило:** селектор вимикача не легший за найважчий профільний і стоїть нижче у файлі. Перевіряти не наявність медіа-запиту, а обчислене значення токена в увімкненому режимі. Калібрувати парою «протікає / залатано». Медіа-запит у файлі означає «записано», а не «діє».
**Перевірка:** емулювати `prefers-reduced-motion: reduce` у кожному профілі й прочитати `getComputedStyle(document.documentElement).getPropertyValue('--amp')`: має бути 0.
**Приклад:**
```css
:root[data-motion=bold] { --amp: 1.5 }                   /* вага 0,2,0 */
@media (prefers-reduced-motion: reduce) {
  :root { --amp: 0 }                                     /* 0,1,0: програє */
  :root, :root[data-motion] { --amp: 0 }                 /* правильно */
}
```
