title: Документація розходиться з реальністю
---
**Симптом:** README описує команди, шляхи й статуси, яких більше немає. Новий розробник чи наступна сесія діє за ним і отримує помилку або хибну картину.
**Корінь:** структуру змінюють одним кроком, а документ «потім». README дистрибутива часто є просто копією README джерела.
**Правило:** документ оновлюється тим самим кроком, що змінює структуру: без цього задача не готова. README дистрибутива пишеться окремо, бо в нього інший читач і інші команди.
**Перевірка:** виконати кожну команду з README на чистому checkout; кожен згаданий шлях перевірити через `test -e`.
**Приклад:** скрипт перейменовано з `run.sh` на `serve.sh`. У тому ж коміті: `git grep -n "run\.sh"` дає нуль, а README містить нову команду, запущену хоч раз.
