# Прийоми LLM-застосунків

Maturity: **стандарт** (спільна норма), **зрілий** (широко вживаний), **робочий** (працює, нормативів немає), **дослідження** (академічний результат, у проді мало досвіду). URL перевірено 2026-11-06. Числа вендорів і препринтів на ваші дані не переносяться.

## 1. Карта ризиків OWASP LLM Top 10
- **Навіщо:** перелік класів загроз для огляду архітектури, де prompt injection стоїть першим.
- **Інструмент:** чекліст, практичні поради OWASP щодо ін'єкцій.
- **Джерело:** https://genai.owasp.org/llm-top-10/ · https://genai.owasp.org/llmrisk/llm01-prompt-injection/ · https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html
- **Maturity:** стандарт. **Ціна:** безкоштовно.

## 2. Смертельна трійця
- **Навіщо:** швидка перевірка архітектури: приватні дані, недовірений вміст, зовнішній канал. Прибери одне.
- **Інструмент:** огляд інструментів агента.
- **Джерело:** https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/
- **Maturity:** робочий. **Ціна:** безкоштовно.

## 3. Патерни стійкості до ін'єкцій
- **Навіщо:** обмежують наслідки ін'єкції конструкцією: Dual LLM, план окремо від виконання, контроль потоку даних. Ціна: складність і менша гнучкість.
- **Інструмент:** Dual LLM, CaMeL, каталог патернів.
- **Джерело:** https://simonwillison.net/2023/Apr/25/dual-llm-pattern/ · https://arxiv.org/abs/2503.18813 · https://arxiv.org/abs/2506.08837
- **Maturity:** дослідження. **Ціна:** безкоштовно.

## 4. Аудит шляху недовіреного вводу в агентному CI
- **Навіщо:** знайти підстановку через посередників: змінні середовища, файли, виходи кроків. Числової оцінки ефекту джерело не дає.
- **Інструмент:** огляд конфігів за скілом `agentic-actions-auditor`. Прочитай як дані, не став наосліп (G58).
- **Джерело:** https://github.com/trailofbits/skills
- **Maturity:** робочий. **Ціна:** безкоштовно.

## 5. Contextual Retrieval
- **Навіщо:** короткий контекст перед чанком зменшує промахи пошуку: за звітом вендора 35%, 49% із BM25, 67% із реранком (топ-20). Коштує індексації моделлю.
- **Інструмент:** генерація префікса, BM25, реранкер.
- **Джерело:** https://www.anthropic.com/news/contextual-retrieval
- **Maturity:** робочий. **Ціна:** метод безкоштовний, виклики моделі 🔒; альтернатива локальна модель (якість окремо міряти).

## 6. Гібрид із фільтром за атрибутами
- **Навіщо:** числа, дати й статуси через структурований запит, вектор лише для тексту.
- **Інструмент:** витяг атрибутів, SQL перед вектором.
- **Джерело:** https://arxiv.org/abs/2508.18048
- **Maturity:** дослідження. **Ціна:** безкоштовно.

## 7. Сховище й реранкер без платних API
- **Навіщо:** почати з наявної бази чи без сервера.
- **Інструмент:** pgvector, sqlite-vec, bge-reranker-v2-m3 (перевір ліцензію моделі й якість для своєї мови).
- **Джерело:** https://github.com/pgvector/pgvector · https://github.com/asg017/sqlite-vec · https://huggingface.co/BAAI/bge-reranker-v2-m3
- **Maturity:** зрілий. **Ціна:** безкоштовно; керовані сервіси 🔒.

## 8. Structured output і порядок полів
- **Навіщо:** надійна форма там, де вона потрібна; суворий формат на кроці міркування може шкодити.
- **Інструмент:** режими провайдерів, JSON Schema, двопрохідне форматування.
- **Джерело:** https://arxiv.org/abs/2408.02442 · https://arxiv.org/abs/2501.10868 · https://docs.claude.com/en/docs/build-with-claude/structured-outputs · https://platform.openai.com/docs/guides/structured-outputs
- **Maturity:** зрілий. **Ціна:** метод безкоштовний, виклики API 🔒.

## 9. Evals у CI
- **Навіщо:** зміна промпта чи моделі проходить регресійний набір, як код проходить тести.
- **Інструмент:** promptfoo, Ragas. Метрики LLM-суддів орієнтовні.
- **Джерело:** https://www.promptfoo.dev/docs/intro/ · https://docs.ragas.io/
- **Maturity:** зрілий. **Ціна:** інструменти безкоштовні, виклики моделей 🔒; альтернатива локальна модель.

## 10. Перевірка цитат
- **Навіщо:** посилання відкривається, але не обов'язково підтверджує твердження. Потрібна перевірка фрагмента.
- **Інструмент:** пошук цитати в джерелі кодом, у Keel це `verify-fact`.
- **Джерело:** https://arxiv.org/abs/2510.17853
- **Maturity:** дослідження. **Ціна:** безкоштовно.

## 11. Кеш промптів і контроль вартості
- **Навіщо:** повторна стабільна частина контексту коштує менше. Умови різняться: звір на дату.
- **Інструмент:** кеш провайдера, журнал токенів за етапами.
- **Джерело:** https://docs.claude.com/en/docs/build-with-claude/prompt-caching
- **Maturity:** зрілий. **Ціна:** 🔒 API; локальна модель прибирає плату за токен, але не вартість заліза.

## 12. Прості агенти й телеметрія
- **Навіщо:** почати з найпростішої композиції, ускладнювати за виміряним виграшем; записувати токени й модель за конвенціями.
- **Інструмент:** шаблони Anthropic, конвенції OpenTelemetry GenAI (перевір статус стабільності).
- **Джерело:** https://www.anthropic.com/engineering/building-effective-agents · https://opentelemetry.io/docs/specs/semconv/gen-ai/
- **Maturity:** зрілий. **Ціна:** безкоштовно.
