# Прийоми самовдосконалення

Maturity: **стандарт** (спільна норма), **зрілий** (широко вживаний), **робочий** (вживаний метод без формальних норм), **дослідження** (академічний чи вендорський результат). URL перевірено 2026-11-06.

## 1. Дизайн навички за документацією
- **Навіщо:** `description` як тригер, тонке тіло, деталі на вимогу.
- **Інструмент:** best practices для Agent Skills, документація Claude Code.
- **Джерело:** https://docs.claude.com/en/docs/agents-and-tools/agent-skills/best-practices · https://code.claude.com/docs/en/skills
- **Maturity:** стандарт для цієї платформи. **Ціна:** безкоштовно.

## 2. Критерії успіху перед правкою промпта
- **Навіщо:** без вимірного критерію правка промпта це вгадування.
- **Інструмент:** набір тестів і критеріїв.
- **Джерело:** https://docs.claude.com/en/docs/test-and-evaluate/develop-tests · https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview
- **Maturity:** зрілий. **Ціна:** безкоштовно; прогони моделі витрачають квоту.

## 3. Порівняння версій промптів
- **Навіщо:** запускати стару й нову версії на тих самих кейсах.
- **Інструмент:** promptfoo або `evals/evals.json` навички вручну.
- **Джерело:** https://www.promptfoo.dev/docs/intro/
- **Maturity:** зрілий. **Ціна:** безкоштовно; виклики моделі 🔒 або квота.

## 4. Ускладнення лише за виміряний виграш
- **Навіщо:** перевіряльний крок корисний там, де є чіткі критерії, інакше зайвий.
- **Інструмент:** виконавець і оцінювач, найпростіша композиція.
- **Джерело:** https://www.anthropic.com/engineering/building-effective-agents
- **Maturity:** зрілий. **Ціна:** безкоштовно.

## 5. Ретро без пошуку винних
- **Навіщо:** факти, таймлайн, системні причини, а не «будь уважнішим».
- **Інструмент:** шаблон постмортему.
- **Джерело:** https://sre.google/sre-book/postmortem-culture/
- **Maturity:** стандарт. **Ціна:** безкоштовно.

## 6. Випробування із відкатом
- **Навіщо:** зміна має час проявити шкоду, а повернення дешеве й простежуване.
- **Інструмент:** `keel overlay` (14 днів, дві скарги), `git revert`.
- **Джерело:** https://git-scm.com/docs/git-revert
- **Maturity:** робочий. Метод Keel поки не виміряно на користь: це бета. **Ціна:** безкоштовно.

## 7. Масштаб загрози в чужих скілах
- **Навіщо:** підстава читати, а не довіряти. Аудит Snyk: 76 скілів зі шкідливим навантаженням серед 3984 проскановано. Це звіт вендора безпеки, частка залежить від майданчика й методу.
- **Інструмент:** читання сирого тексту до встановлення.
- **Джерело:** https://snyk.io/blog/toxicskills-malicious-ai-agent-skills-clawhub/
- **Maturity:** дослідження. **Ціна:** безкоштовно.

## 8. Академічний огляд шкідливих скілів
- **Навіщо:** незалежне дослідження прийомів приховування в скілах.
- **Інструмент:** стаття як перелік ознак для ручного читання.
- **Джерело:** https://arxiv.org/abs/2602.06547
- **Maturity:** дослідження (препринт). **Ціна:** безкоштовно.

## 9. Конфіг чужого репозиторію як поверхня атаки
- **Навіщо:** файли проєкту можуть виконуватись. Відкривай незнайомий репозиторій обережно, оновлюй клієнт.
- **Інструмент:** запис CVE, читання конфігів до запуску.
- **Джерело:** https://nvd.nist.gov/vuln/detail/CVE-2025-59536
- **Maturity:** стандарт (база CVE). **Ціна:** безкоштовно.

## 10. Ланцюг постачання для AI-компонентів
- **Навіщо:** плагіни, моделі й набори даних теж залежності.
- **Інструмент:** розділ LLM03 OWASP.
- **Джерело:** https://genai.owasp.org/llmrisk/llm032025-supply-chain/
- **Maturity:** стандарт. **Ціна:** безкоштовно.

## 11. Огляд чужих правил як ідей
- **Навіщо:** публічний приклад якісних навичок безпеки. Навіть авторитетний набір читай як дані й переказуй своїми словами.
- **Інструмент:** читання репозиторію без встановлення.
- **Джерело:** https://github.com/trailofbits/skills
- **Maturity:** робочий. **Ціна:** безкоштовно.
